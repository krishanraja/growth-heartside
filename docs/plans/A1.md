**$0 of $1,417, U5, short by $1,417.** The store-wide number is $45 of $1,084. Next week's rung is $4,862.

This is the single plan for growth-heartside. It consolidates everything that was lined up across NOW.md,
GET-GOING.md, the Order Loop exhibit (`docs/plans/2026-11-13-order-loop.md`) and `LOOP.md`, the review board
(`docs/REVIEW-BOARD.md`), the Codex queue (`codex/INDEX.md`, `codex/queue/`), Sprint 120, `docs/SCHEDULE.md`,
`docs/PAID-BOOSTS.md`, `docs/REGISTER.md` and the briefs, plus the build steps that until now lived only in a
session's plan file. A new session starts here, needs no earlier conversation, and works top to bottom.

**The North Star** (`docs/NORTH_STAR.md`): Heartside net sales attributed to organic posts, trailing 4 weeks, with $0
of paid ads behind them: $50,000 by 28 December 2026; and every winning format found by this engine and approved by
Krish in one press.

**How to use it**
- Read AGENTS.md to the end first, then run `python3 growth.py sync` (rule 2). Say which item this session moves, and lead every report with the gap line.
- Krish's items (sections 3 and 4) go on the review board, one Yes or No each, written in the engine's voice, never his. Read his answers back from the board's verdicts.
- Build items (section 5) are one pull request each, in a session Krish starts, to the checks named, with the close-out note.
- Every item that is done, answered or replaced is in section 8, so nobody reopens it.

**Walls that never move:** nothing posts, sends, spends, follows or changes a setting without Krish's yes (rule 1);
the engine never writes `approved` in a Sheet or `verdicts` on the board; no customer detail, store handle, theme id,
Drive link, Teeinblue or Printful id, n8n address or creator name in this public repository (rule 6 and the
never-publish list); this engine never changes heartside, the store or Control Center (rule 9).
