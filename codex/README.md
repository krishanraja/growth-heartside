# Codex lane

Claude directs, Codex makes (ai-harness `tool-router`, "Creative production"). This is the same lane heartside
runs (`krishanraja/heartside` `codex/README.md`), set up here so this engine's films can be built without
touching heartside (rule 9). Ruling (Krish, 2026-11-02): add a Codex lane to this repository.

Codex runs only on Krish's home computer, inside WSL Ubuntu. That computer's recordings pass (content-engine
`scripts/velib/codex_lane.py`, `config/codex-lanes.json`) checks each repository listed in `codex-lanes.json`
every five minutes for a card in `codex/queue/`, builds it, and pushes the result back. **This repository must be
listed there** (`krishanraja/growth-heartside`), which Krish adds on that computer.

A session queues work like this:

1. **Write the card** at `codex/queue/<id>.md`, where `<id>` is lowercase words joined by hyphens, using the
   template below. Name every input file it may read and every path it may write. Codex has no tool
   connections, so any Higgsfield or Runway still or clip it needs is generated by Claude first and committed
   as an input under `codex/inputs/<id>/`.
2. **Book it.** Call Control Center's `reserve_credit_spend` (engine `growth-heartside`, pool `codex`, amount
   the card's expected allowance points, 1 if unsure) and put the returned id in the card as `spend_id`.
   Without a booking the computer refuses the card. A refusal (`no_pool`, `held`, `over_share`) is Krish's
   placement to change in Control Center: say so in one line, do not queue.
3. **Push it** on main or this session's `claude/` branch. Codex's worktree is cut from that branch.
4. **Read the result** from the branch `codex/<id>`: `git fetch origin codex/<id>`, then
   `codex/results/<id>.json` says `ok` and any problems. Re-run the acceptance yourself, look at the output at
   full size, then merge it or open a pull request from it.
5. **Settle** the booking with `settle_credit_spend` (the actual cost; 0 if it failed).

A card is built once: the branch `codex/<id>` marks it done. To run it again, use a new id.

## This repository is public, so the lane is picture-only

- **Never commit licensed or private audio**: Epidemic Sound music and effects, and the ElevenLabs voice reads
  stay out of git. Codex builds the **silent picture** to a timing file (`codex/inputs/<id>/timeline.json`:
  each shot's start, end, still, on-screen words and captions). The Claude session that queued the card adds
  the locked sound mix to Codex's picture and does the full-size check with sound.
- **Never commit a customer's anything** (AGENTS.md rule 6). Inputs are AI stills, the live store's own
  renders and the approved breed examples only.
- **The product is never generated** (AGENTS.md rule 4). Codex composites the real render unchanged, with
  the Example label. Generators never touch the product's printed design.

## Direction first

Nothing is built until Krish has approved its direction: the animatic or storyboard on his board, with his
yes recorded in `docs/briefs/` and `CHANGES.md` (heartside's "Direction first", Krish 2026-11-01). A change he
asks for is a new version, shown again.

## Card template

```markdown
---
card: <id>
title: One line naming the asset
spend_id: <the id reserve_credit_spend returned>
max_minutes: 40
max_calls: 40
write_allow: [codex/out/<id>/*]
---
## Goal
What to make, for whom, and the one point it must land. The approved direction: the timeline file, type
(Fraunces for the big line, Karla for captions, Courier Prime for the dog's words), colors (cream, ink, stamp
red once), 9:16 at 1080x1920, 30 fps, and the exact input files under codex/inputs/<id>/.

## Acceptance
python3 codex/check_picture.py codex/out/<id>/picture.mp4 codex/inputs/<id>/timeline.json

## Return
The files made, and anything that could not be done.
```

Acceptance lines start with `pnpm`, `npm run`, `npx`, `node` or `python3`; anything else is ignored.
